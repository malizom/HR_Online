# People Portal — desktop demo

Runs the whole demo on your own computer: nothing hosted, nothing billed.

1. Install **Docker Desktop** (free for small businesses) and start it.
2. Download this repository (GitHub → Code → Download ZIP) and unzip it.
3. Open the `demo` folder and double-click **Start MVR Demo** (Mac) or **Start MVR Demo.bat** (Windows).
   On a Mac the first time: right-click → Open, because the file came from the internet.
4. Your browser opens the sign-in page; the window shows the **access code**. Pick a person and sign in.

- **Fresh data before a meeting:** double-click **Fresh data** (leave dates are re-based on today).
- **Stop:** press any key in the window, or quit Docker Desktop.
- Names are from MVR's public team page; every leave record, document and figure is invented.
- Want MVR to click it themselves? Use the Codespaces option instead (see `.devcontainer/README.md`).
